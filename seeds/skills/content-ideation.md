# Content-Ideation

Ein Thema ist kein Content. Ein Winkel ist Content. Aus einem Thema lassen sich zehn Stücke machen, wenn man die Perspektive dreht.

## Von 1 Thema zu vielen Winkeln

Dreh das Thema durch diese Linsen:

- **Wie-Frage** — Anleitung, Schritt-für-Schritt. „Wie X in 20 Minuten"
- **Warum-Frage** — Ursachen, Mechanik. „Warum X meistens scheitert"
- **Fehler / Anti-Muster** — Was man falsch macht. „Die 3 Fehler bei X"
- **Kontra-These** — Gegen die gängige Meinung. „X wird überschätzt"
- **Vergleich** — X vs. Y, vorher/nachher. „X oder Y — was wann?"
- **Story / Case** — Konkrete Erfahrung. „Was X mich bei Projekt Y gelehrt hat"
- **Daten / Beobachtung** — Zahl als Aufhänger. „Wir haben X 100x gemacht. Das kam raus."
- **Definition / Klärung** — Begriff schärfen. „Was X wirklich bedeutet"
- **Prognose** — Wohin es geht. „Warum X in 12 Monaten Standard ist"
- **Kontrarian-Take auf Aktuelles** — Ein Trend, eingeordnet.

## Vorgehen

1. **Thema und Zielgruppe klären** (ask_user, falls unklar): Worum geht es, für wen, welches Ziel?
2. **8-12 Winkel generieren** über die Linsen oben. Konkret formulieren, nicht „etwas über X".
3. **Priorisieren** nach: Relevanz für die Zielgruppe × eigene Substanz (kann ich dazu was Echtes sagen?) × Aktualität.
4. **Format vorschlagen** je Winkel (LinkedIn-Post, Long-form, Carousel, Video). Manche Winkel passen besser zu manchen Kanälen.

## Output

Eine priorisierte Tabelle: Winkel | Format | Hook-Idee | warum relevant. Auf Wunsch ein Winkel direkt ausarbeiten (dann passenden Craft-Skill laden: `linkedin-craft`, `long-form-struktur`, `carousel-struktur`, `video-script-craft`).

## Prinzip

Lieber zehn scharfe Winkel als ein „umfassender" Beitrag. Ein Winkel = eine Aussage = ein Stück Content.
